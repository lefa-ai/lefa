# Lefa

**Open computer use for Linux.** Lefa gives AI agents eyes and hands on any Linux machine — screenshots, accessibility trees, and native input — exposed as clean [MCP](https://modelcontextprotocol.io) tools any model can drive.

> **Early days.** We're building Lefa in the open, and the code hasn't landed here yet. Watch the repo, or join the waitlist at [lefa.ai](https://lefa.ai) to get one email when it ships.

## What's planned

- Perception via AT-SPI accessibility trees + screenshots
- Native input on Wayland and X11
- Rust core: `lefa`, `lefad`, and `lefa-mcp`
- Runs where your agents run — laptop, server, or your cloud
