About Lefa

The Agent IDE.

Lefa is an independent software startup building an open source desktop environment for engineers who work with coding agents. It was founded in Oakland, California in 2026 by Marcos Hernanz.

What we're building

Every task gets its own workspace, with checkpoints, forks, diffs, and configurable agents that can use different models. Lefa is model-neutral and built around a minimal first-party agent harness rather than a terminal wrapper.

Where it is going

The initial macOS product is in active development, with a public launch planned for November 2026. Persistent cloud workspaces, secure task execution, artifact storage, model inference, and Lefa-specific evaluation and fine-tuning runs will support reliable agent workflows across desktop and web.

Built in public

The source code and active development history are public at github.com/lefa-ai/lefa. For product, partnership, or verification questions, email m@lefa.ai.
